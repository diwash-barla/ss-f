API Reference

Complete documentation for Spark Studio's Elite Proxy Backend.

Authentication

All API endpoints are protected via an Elite Proxy Layer. You must pass your Custom Frontend Key (`SS_API_KEY`) as a Bearer Token in the headers.

HTTP Header
Authorization: Bearer <YOUR_SS_API_KEY>
POST /api/fast-search

Performs a quick search query across the database. Returns matched URLs and snippets.

Request Payload (JSON)
{
  "query": "What is quantum mechanics?",
  "threshold": 0.7
}
POST /api/research/start

Initiates a background multi-source scanning process. Returns a task ID to poll for status.

Request Payload (JSON)
{
  "query": "Eridanus Supervoid"
}
Response
{
  "status": "processing",
  "task_id": "task_abc123"
}
GET /api/research/status/{task_id}

Poll this endpoint to get live terminal logs and the final synthesis report.

Response (When Complete)
{
  "status": "complete",
  "logs": [
    { "msg": "Data extracted...", "color": "green" }
  ],
  "result": {
    "urls": [...],
    "data": { ... Synthesis Report JSON ... }
  }
}
POST /api/extract

Bypasses firewalls to extract clean text, images, and videos from a specific URL.

Request Payload (JSON)
{
  "url": "https://example.com/article"
}
POST /api/generate-script

AI generates a highly engaging YouTube/Reels script based on the researched data.

Request Payload (JSON)
{
  "query": "Topic Name",
  "research_data": { ... JSON from Deep Scan ... }
}
Response
{
  "script": "[Hook]\nDid you know..."
}
POST /api/dispatch-to-creator

Sends the finalized script to the Vidspark API for video generation.

Request Payload (JSON)
{
  "script_text": "The final edited script...",
  "topic": "Video Title",
  "orientation": "vertical" // or "horizontal"
}
